# 安裝與使用（Linux）

這一頁是 Linux 版的安裝、加入輸入來源與移除。單字的打法、字根表、補字與更新和 macOS 版相同，見 [安裝與使用](guide-macos.md)；注音打詞、首碼聯想與字彙建議，Linux 版 1.4.0 也有，按法和 macOS 頁的同名各節相同，Linux 版不同的地方見本頁的「注音打詞」「首碼聯想與字彙建議」。

**請先看這段**：Linux 版的套件沒有 GPG 簽章，也不在各發行版的官方套件庫裡。請只從 GitHub 上 `zizai-ime/zizai-ime` 的 [Releases](https://github.com/zizai-ime/zizai-ime/releases) 下載，安裝前先核對 SHA-256（「下載與核對」的第 2 步）。

想先看整體的樣子：[功能預覽影片（手繪動畫，約半分鐘）](https://youtu.be/HSc9Hmme0D4)。

## 系統需求

- x86_64（64 位元的 Intel、AMD）電腦。還沒有 ARM64 版。
- 輸入法框架：IBus 1.5 以上（GNOME 等），或 Fcitx5 5.1.7 以上（KDE 等）。
- 有現成套件的發行版：
  - Ubuntu 24.04、26.04，Debian 13：`.deb`
  - Fedora 43、44：`.rpm`
- 其他發行版（包括 Arch Linux）用通用版 `ZiZai-Linux-x64-<版本>.tar.gz` ，要 glibc 2.39 以上（和 Ubuntu 24.04 同期或更新的發行版）。
- 上面列出套件的發行版，以及用通用版的 Arch Linux，都在乾淨的系統裡裝好，用 IBus 與 Fcitx5 的自動測試打字確認過；1.4.0 還沒有在實際的桌面上試過。

## 下載與核對

Linux 版的最新版本是 1.4.0，更新內容與 SHA-256 見 [字在 1.4.0](https://github.com/zizai-ime/zizai-ime/releases/tag/v1.4.0)。

1. 到 [字在 1.4.0](https://github.com/zizai-ime/zizai-ime/releases/tag/v1.4.0) 下載。檔名裡有發行版的名稱：

   | 發行版 | 格式 | 檔名裡的字 |
   |---|---|---|
   | Ubuntu 24.04、26.04 | `.deb` | `ubuntu24.04` 、`ubuntu26.04` |
   | Debian 13 | `.deb` | `debian13` |
   | Fedora 43、44 | `.rpm` | `fc43` 、`fc44` |
   | 其他發行版（包括 Arch Linux） | `.tar.gz` | 只有一個檔： `ZiZai-Linux-x64-<版本>.tar.gz` |

   `.deb` 與 `.rpm` 每個發行版有三個檔，下載其中兩個： `zizai` （內建資料與「字在設定」，一定要），加上 `ibus-zizai` （GNOME 等用的 IBus）或 `fcitx5-zizai` （KDE 等用的 Fcitx5）。兩個框架都有在用，就三個都裝。不知道用的是哪一個，在終端機執行 `pgrep -l 'ibus-daemon|fcitx5'` ，看列出的是 `ibus-daemon` 還是 `fcitx5` 。
2. 再下載 `SHA256SUMS` ，放在同一個資料夾，在那個資料夾執行：

   ```sh
   sha256sum -c --ignore-missing SHA256SUMS
   ```

   你下載的每個檔後面都要是「OK」（有些系統顯示「成功」）。出現「FAILED」（或「失敗」）就不要安裝，刪掉重新下載。

## 安裝

在放下載檔的資料夾執行下面的指令。資料夾裡只放這次下載的檔，舊版的先刪掉。用 Fcitx5 的話，把 `ibus-zizai` 換成 `fcitx5-zizai` 。

- Ubuntu、Debian：

  ```sh
  sudo apt install ./zizai_*.deb ./ibus-zizai_*.deb
  ```

- Fedora：

  ```sh
  sudo dnf install ./zizai-*.rpm ./ibus-zizai-*.rpm
  ```

- 其他發行版（通用版）：

  ```sh
  tar xf ZiZai-Linux-x64-<版本>.tar.gz
  cd ZiZai-Linux-x64-<版本>
  sudo ./install.sh
  ```

  缺少系統程式庫時，裝好後會列出來，請用發行版的套件管理程式補裝。解開的資料夾請留著，移除時要用。

程式裝在 `/usr` ，詞庫、擴充字根表與設定在 `~/.local/share/zizai` 。

升級：下載新版，照同樣的步驟再裝一次，不必先移除。詞庫、擴充字根表與設定都會保留。

2. 選「中文 (臺灣)」，再選「中文 (字在)」，按「加入」：

   <img src="images/linux-2-add-source.png" width="420" alt="「加入輸入來源」對話框，要選的是「中文 (字在)」，再按「加入」">

**Fcitx5**：打開「Fcitx 5 設定」，在「輸入法」把「字在」加到目前的輸入法，按「套用」。

## 切換輸入法

- **GNOME**：按 Super＋空白鍵（Super 多半是有 Windows 標誌的那顆鍵），或從畫面右上角的輸入來源選單選「中文 (字在)」。切到字在時，右上角顯示「字」。
- **Fcitx5**：按 Ctrl＋空白鍵（Fcitx5 的預設），或從系統匣選。

字在沒有自己的中英切換鍵，要打英文就切回英文的輸入來源。

### 四種輸入法

Linux 版 1.4.0 起有四種輸入法：大易、倉頡、標準注音，以及倚天 26 鍵（標準注音的另一種鍵盤排列），都在「字在」裡面，不用另外加輸入來源。

- 在輸入法選單切換：GNOME 是畫面右上角的輸入來源選單，Fcitx5 是系統匣裡「字在」底下的選單。第一行（目前用的字根表）下面列出啟用的輸入法：大易、倉頡、標準注音、標準注音（倚天 26 鍵），選一項就換過去。只啟用一個時不列。
- 不用的輸入法、預設的輸入法與切換的快速鍵，在「字在設定」的「輸入法」分頁、左側「使用中的輸入法」設定；至少要留一個。

## 打字與選字

單字的打字與選字、三碼（由四碼推導）與四碼、推導二碼、標點與符號、字根表，和 macOS 版相同，見 [安裝與使用](guide-macos.md) 的「打字與選字」「三碼與四碼」「標點與符號」「字根表」各節。

倉頡、標準注音（含倚天 26 鍵）、注音打詞、首碼聯想、字彙建議與字彙領域，Linux 版 1.4.0 起也有，按法和 macOS 版相同，見 macOS 頁的「輸入法」「倉頡」「標準注音」「注音打詞」「首碼聯想」「字彙建議」「字彙領域」各節；Linux 版不同的地方見下面「注音打詞」「首碼聯想與字彙建議」「動態字序」三節。字在與任何輸入法廠商沒有合作或隸屬關係，也未經其背書。

<img src="images/linux-typing-symbol.png" width="640" alt="文字編輯器裡按符鍵再按句點那顆鍵，組字區顯示「符.」，候選字視窗列出以「。」開頭的中文標點">

選項在輸入法選單：GNOME 是畫面右上角的輸入來源選單，Fcitx5 是系統匣裡「字在」底下的選單。

<img src="images/linux-3-menu.png" width="394" alt="GNOME 右上角的輸入來源選單，字在的選項：從「字根表：內建自建字根表」到「關於字在」">

- 字在的第一行是目前用的字根表，例如「字根表：內建自建字根表」；下面是四種輸入法（見「四種輸入法」）。
- 以四碼為主（預設）／以三碼為主、推導二碼（三碼、四碼字取首尾）（預設開啟）、符鍵（=）用清單選字（預設關閉）、打錯時發出提示音（預設開啟）：和 macOS 版相同。
- 保守智慧首選（實驗）：還在試驗的選項，預設關閉。
- 只列出常用字集的字（預設開啟）、隱藏字型顯示不出來的字（預設開啟）、隱藏系統字型沒有的字（預設關閉）：見下面的「擴充區的字」。
- 「檢查更新…」「擴充字根表…」「打開字在設定…」「編輯符號…」「關於字在」：打開「字在設定」的對應分頁。

## 注音打詞

1.4.0 起，標準注音預設打詞，按法和 macOS 版相同，見 [注音打詞（macOS）](guide-macos.md#注音打詞)。Linux 版要注意的地方：

- 只在標準注音的標準排列；倚天 26 鍵排列這一版只能逐字。
- 打字時，候選排成一列跟在「Tab｜」後面：IBus 顯示在輔助文字那一行；Fcitx5 顯示在候選字視窗下方，沒有顏色，選到的那一格用醒目標示。兩個框架選到的那一格都另外加上「［ ］」，因為 GNOME 的候選字視窗不顯示底色。按空白鍵或向下鍵開始選字時，才出現每一格標出選字鍵的候選字視窗。
- 切換打詞與逐字：在「字在設定」的「輸入法」分頁、左側「標準注音」子頁的「注音打詞」。改了之後，正在打的字會放棄，要重打。
- Linux 版沒有 macOS 版第一次用到注音打詞時的說明。
- 選過的詞記在這台電腦，和單字的學習紀錄放在一起，「清除動態字序紀錄」時一起清掉，見「動態字序」。

## 首碼聯想與字彙建議

1.4.0 起，大易與標準注音（標準排列）有首碼聯想（預設開啟）與字彙建議（預設關閉），按法和 macOS 版相同，見 [首碼聯想](guide-macos.md#首碼聯想)、[字彙建議](guide-macos.md#字彙建議) 與 [字彙領域](guide-macos.md#字彙領域)。倉頡與倚天 26 鍵排列沒有這兩個功能。IBus 與 Fcitx5 都有。字在與任何輸入法廠商沒有合作或隸屬關係，也未經其背書。

- **開關**：在「字在設定」的「輸入法」分頁、左側「字彙聯想」：首碼聯想、聯想提示、字彙建議、不顯示字彙建議的 App，以及字彙領域（預設只勾高中以下的教科書名詞）。
- **提示與字彙建議**：都和打詞的那一列一樣，由 IBus 或 Fcitx5 顯示，位置跟著桌面的候選字視窗。
- **不顯示字彙建議的 App**：Linux 版照程式名稱判斷，預設是常見的終端機程式。這一版不能自己加 App，只能「移除」或「恢復預設」。IBus 要 1.5.28 以上才判斷得出是哪個程式；在判斷不出是哪個 App 的環境裡（例如 GNOME 的 Wayland 工作階段），清單可能不起作用，終端機裡也會出現字彙建議。
- **密碼欄位**：App 有正確而且即時地告訴輸入法那是密碼欄位時，首碼聯想與字彙建議停用、動態字序不記；App 沒有標示或告知得晚的時候分辨不出來。無痕或「不要學習」的欄位，兩個功能照常作用，但送出的字詞不記次數。
- **前面的字**：只放在記憶體裡、不寫進磁碟。換 App、切換到字在以外的輸入法、登出，或打了標點、換行之後，就從頭算起；換到另一個欄位通常也會從頭算起。在同一個欄位裡用滑鼠移動游標，要 App 通知字在才會重算。
- **打開字在設定**：輸入法選單裡是「打開字在設定…」，不是 macOS 版的「設定⋯」。
- **「關於」分頁**：沒有 macOS 版那一句詞的來源說明；詞與讀音的出處照樣列在同一頁的「資料來源與授權」。
- **詞庫**：隨套件附上，裝在 `/usr/share/zizai` 底下，不連網下載；和「我的詞庫」分頁無關。

## 動態字序

Linux 版 1.4.0 起，大易、倉頡、標準注音（含倚天 26 鍵排列）的候選字順序都會依你的選字習慣慢慢調整，規則和 macOS 版相同，見 [動態字序](guide-macos.md#動態字序)；標準注音打詞時選過的詞也會往前排。這個功能一律開啟，不用設定。

- **小點記號**：位置換過的候選（往前排的字，和因此往後一格的字），選字鍵旁會有一個小點。
- **清除**：在「字在設定」首頁的「進階」按「清除動態字序紀錄」，就回到原本的順序。Linux 版的候選字視窗沒有 macOS 版右鍵選單的「還原這組的順序」。
- **不連網**：紀錄存在這台電腦的 `~/.local/state/zizai/learn/` （設了 `XDG_STATE_HOME` 時改用它），不記句子、前後文、時間，也不會傳出去。字在沒有另外排除備份，備份整個家目錄的工具會包含它，見 [隱私權政策](../PRIVACY.md#動態字序)。

## 擴充區的字

「只列出常用字集的字」預設開啟，擴充 B 以後的罕用字不會出現在候選字視窗；自己補的字和擴充字根表的字照樣出現。想打這些字，在輸入法選單取消勾選這一項。

取消之後，所有字型都顯示不出來的字，「隱藏字型顯示不出來的字」（預設開啟）會藏起來。想打這些字，可以安裝全字庫的字型：

1. 到政府資料開放平臺的全字庫資料集（ https://data.gov.tw/dataset/5961 ）下載 `Fonts_Sung.zip` （全字庫宋體）；要楷體可以另外下載 `Fonts_Kai.zip` 。
2. 解壓縮，把字型檔放進 `~/.local/share/fonts` ，再執行 `fc-cache -f` 。
3. 登出再登入，字在會重新檢查哪些字顯示得出來。

「隱藏系統字型沒有的字（即使另外裝了字型）」預設關閉。打開後，只有另外安裝的字型才顯示得出來的字也不列入候選；對方看不看得到，仍要看對方的電腦與字型。發行版的套件裝在 `/usr/share/fonts` 的字型算系統字型，其他位置的（例如 `~/.local/share/fonts` ）算另外安裝的。

全字庫字型由全字庫網站提供，依政府資料開放授權條款或 SIL Open Font License 1.1 授權；字在不附字型檔。

## 移除

1. 先把「字在」從輸入來源拿掉。GNOME：「設定」→「鍵盤」→「輸入來源」，按「中文 (字在)」右邊的「⋮」→「移除」：

   <img src="images/linux-4-remove.png" width="980" alt="「輸入來源」裡「中文 (字在)」的「⋮」選單，要按的是「移除」">

2. 移除套件。`ibus-zizai` 、`fcitx5-zizai` 會跟著 `zizai` 一起移除：
   - Ubuntu、Debian：`sudo apt remove zizai`
   - Fedora：`sudo dnf remove zizai`
   - 通用版：在當初解開的資料夾執行 `sudo ./uninstall.sh` 。
3. 登出再登入。

詞庫、擴充字根表、設定與匯入的資料更新檔（ `~/.local/share/zizai` ），以及動態字序的紀錄（ `~/.local/state/zizai` ）會留著，重新安裝後還能用。不要了的話，刪掉這兩個資料夾，見 [隱私權政策](../PRIVACY.md)。

## 目前的限制

- 還沒有 ARM64 版。
- 套件沒有套件庫，不會跟著系統更新。有沒有新版，可以在「字在設定」的首頁按「檢查更新」。
- 候選字視窗由 IBus 或 Fcitx5 畫，外觀跟著桌面的主題。
- 切到字在時，IBus 改用美式鍵盤配置，字根鍵的位置才不會跟著鍵盤配置變；Fcitx5 用輸入法群組的鍵盤配置。
- 「字在設定」的「符號」分頁不能切換符鍵（=）的用法，請用輸入法選單。
- GNOME「輸入來源」裡「中文 (字在)」的「⋮」→「偏好設定」還沒有作用，選項請用輸入法選單。
- 還沒在實際的桌面上測過 KDE Plasma，以及 Firefox、LibreOffice、終端機、Chromium 與 Electron 的 App、Qt 的程式。遇到打不出字的 App，請回報。

遇到問題請到 GitHub 的 [Issues](https://github.com/zizai-ime/zizai-ime/issues) 回報。Issues 是公開的：不要貼系統記錄的原文，也不要上傳 `user.db` 、`user.pack` 或含個人資料的截圖；需要記錄時，我們會說明只要哪幾行。
