# 常見問題

## 字在是什麼？

「字在」是以大易輸入法的字根為基礎，依字的部件與筆順重新拆碼的中文字根輸入法，為正體中文（繁體）設計。內建字根表，裝好就能打字。見 [首頁](../README.md)。

## 支援哪些系統？

| 系統 | 需求 |
|---|---|
| macOS | macOS 13 以上，支援 Apple 晶片與 Intel |
| Windows | Windows 10、11。64 位元與 32 位元的檔案不同 |
| Linux | x86_64。IBus 與 Fcitx5 都能用 |
| Android | Android 8 以上 |
| iPhone、iPad | iOS 17、iPadOS 17 以上 |

macOS 版有大易、倉頡、標準注音、倚天 26 鍵（標準注音的另一種鍵盤排列）四種輸入法，在輸入法選單切換；Windows 版 1.3.1 起、Linux 版與手機版（Android、iPhone、iPad）1.4.0 起也有這四種：Windows 在工作列的「中」「英」按鈕按右鍵切換，Linux 在輸入法選單切換，手機長按鍵盤上的「英／中」鍵切換。

注音打詞 1.4.0 起五個平台都有；首碼聯想與字彙建議 1.4.0 起 macOS、Windows、Linux 版有，手機版沒有。見下面「標準注音可以打詞嗎？」與「首碼聯想、字彙建議是什麼？」。

各版本的版本號與下載見 [首頁的下載](../README.md#下載)，安裝步驟見各平台的安裝與使用：[macOS](guide-macos.md)、[Windows](guide-windows.md)、[Linux](guide-linux.md)、[Android](guide-android.md)、[iPhone、iPad](guide-ios.md)。

## 標準注音可以打詞嗎？

可以。1.4.0 起，五個平台的標準注音都預設打詞。電腦版（macOS、Windows、Linux）：打第一個鍵就有候選，可以連打幾個字再選詞，每個字只打聲母也找得到詞；選過的詞會往前排。打字時候選排成一列跟在「Tab｜」後面，按 Tab 輪流選，選到之後按空白鍵送出；也可以按空白鍵開始選，再按上排數字鍵選定：最後一個字還沒標聲調、可以是一聲時，按一下空白鍵是把它當成一聲，留在原地可以接著打；已經有聲調，或這個讀音沒有一聲時，按空白鍵就打開候選字視窗。空白鍵不會直接送出字。打第一個字的讀音時，這一列前面還有首碼聯想接在後面的詞。想一個字一個字選，在「字在設定」的「輸入法」分頁、「標準注音」子頁把「注音打詞」改成「逐字」。按法見 [注音打詞](guide-macos.md#注音打詞)；Windows、Linux 和 macOS 不同的地方見 [Windows](guide-windows.md#注音打詞) 與 [Linux](guide-linux.md#注音打詞)。

手機版（Android、iPhone、iPad）1.4.0 起也預設打詞：候選列分兩行，上面是詞、下面是第一個字的候選，點一下就送出；想逐字選，在字在 App 標準注音頁的「打字方式」改成「逐字」。見 [Android](guide-android.md#注音打詞) 與 [iPhone、iPad](guide-ios.md#注音打詞)。

倚天 26 鍵這一種排列，電腦版 1.4.2 起也預設打詞，和標準排列共用「注音打詞」這個設定，改成逐字時兩種排列都逐字；手機版還是逐字選字。

## 首碼聯想、字彙建議是什麼？

都是 macOS、Windows、Linux 版的功能（1.4.0 起大易與標準注音（標準排列），標準注音打詞或逐字都有；1.4.2 起倉頡與倚天 26 鍵排列也有；手機版沒有），用詞庫幫你把詞一次打完：

- **首碼聯想**（預設開啟）：送出一個字後，打下一個字的第一個鍵，游標旁會提示接在後面的詞。組字中按 Tab，只有一個詞就直接送出，兩個以上時在提示裡輪流選，按空白鍵送出，或直接打下一個字。見 [首碼聯想](guide-macos.md#首碼聯想)。
- **字彙建議**（預設關閉）：剛送出字、還沒打下一個字時，游標旁先用淡色顯示可能接著打的詞。按 Tab 採用，有幾個建議時在建議之間輪流選，按空白鍵送出，或直接打下一個字。見 [字彙建議](guide-macos.md#字彙建議)。

兩個開關都在「字在設定」的「輸入法」分頁、「字彙聯想」子頁。詞庫收常用詞、教育部《國語辭典簡編本》《成語典》的詞條，以及國家教育研究院樂詞網各領域的名詞，都內附在安裝檔裡，不連網查詢，也和「我的詞庫」分頁無關。樂詞網的領域在同一頁的「字彙領域」勾選，預設只有高中以下的教科書名詞，勾得再多也不會拖慢，見 [字彙領域](guide-macos.md#字彙領域)。字在與任何輸入法廠商沒有合作或隸屬關係，也未經其背書。

## 打開字彙建議後，Tab 不能換欄位了？

字彙建議顯示的時候，Tab 會被拿去採用建議，所以在網頁表單打完字、建議還在時按 Tab，會採用建議，不會換到下一欄；程式編輯器的縮排也一樣；要換欄位或縮排，先按 Esc 讓建議消失。建議沒有顯示時，Tab 照原本交給 App。

遇到時先打其他鍵讓建議消失，或在「字在設定」的「字彙聯想」把那個 App 加進「不顯示字彙建議的 App」（macOS、Windows），也可以把「字彙建議」關掉（預設就是關的）。清單預設有終端機類的 App：macOS 是「終端機」與 iTerm2，Windows、Linux 是常見的終端機程式。Linux 版這一版不能自己加 App，只能移除或恢復預設；在判斷不出是哪個 App 的環境裡（例如 GNOME 的 Wayland 工作階段），清單可能不起作用。

Word 與 Google 文件的表格裡，Tab 會先被拿去跳到下一格，字彙建議在那裡按 Tab 選不到詞；首碼聯想照樣可以用。不建議為了表格把 Word 或瀏覽器加進清單，那樣整個 App 都不會顯示字彙建議。

macOS 的 Chrome 裡，有些網頁自己做的編輯器會把選詞用的 Tab 也拿去用，Safari 也可能這樣，見 [目前的限制](guide-macos.md#目前的限制)。

## 要付費嗎？

不用。字在是免費軟體，個人或工作上使用都可以；但目前沒有開放原始碼，也不是開源軟體。見 [使用條款](../LICENSE.md)。

## 會不會收集我打的字？

不會。

- 字在沒有把你打的字、詞庫、擴充字根表或記錄檔傳給字在開發小組的功能，也不回傳使用統計，不放廣告。
- 電腦版的輸入法本體沒有連網的功能。只有在「字在設定」按「檢查更新」或「下載並看改了哪些字」時，才會連到 GitHub，請求裡沒有你的資料；不會自動檢查。
- 1.4.0 起（倉頡與倚天 26 鍵排列是 1.4.2 起），macOS、Windows、Linux 版的首碼聯想與字彙建議，會看你剛送出的最後幾個字來找詞。這些字只在打字當下放在記憶體裡、不寫進磁碟，也不傳出去；密碼欄位裡，macOS 版在系統開啟安全輸入時兩個功能都不作用，Windows 版與 Linux 版在 App 有正確而且即時地告訴輸入法時停用。注音打詞時選過的詞，以及用首碼聯想、字彙建議送出的詞，和單字一樣記在這台電腦上，不傳出去，會不會被備份見隱私權政策；按「清除動態字序紀錄」會一起清掉。
- 手機版 1.4.0 起，標準注音打詞時一個字一個字選出來、詞庫沒有的詞，記在手機上的「我的詞庫（注音詞）」，不傳出去；Android 版不參與雲端備份與裝置間移轉，iOS 版標成不進 iCloud 與電腦的備份。
- Android 版有網路權限，只在你在字在 App 的「版本與更新」按了檢查或下載時連到 GitHub，鍵盤的程式不連網；iOS 版不要求「允許完整取用」，iOS 不讓字在的鍵盤連網。
- Windows 版預設會在你的電腦上寫一份記錄檔，記下啟用、載入、錯誤這類事件，以及當時在用的 App 名稱；不記錄你打的字。

詳細內容見 [隱私權政策](../PRIVACY.md)。

## 字根表怎麼更新？

電腦版在「字在設定」的首頁按「檢查更新」。有新的資料更新檔時，按「下載並看改了哪些字」，看過改了輸入碼的字再按「套用」，不必重裝字在。詞庫、擴充字根表與設定不受影響，想換回內建的資料，按「改回內建資料」。見 [版本與更新](guide-macos.md#版本與更新)。

也可以自己從 [zizai-data 的 Releases](https://github.com/zizai-ime/zizai-data/releases) 下載資料更新檔（ `.zizaipack` ），在首頁按「匯入資料更新檔…」。

## 怎麼升級到新版？

- macOS：「檢查更新」看到新版時，按「前往下載頁」，下載新的安裝檔，照安裝步驟裝一次。詞庫、擴充字根表與設定都會保留。
- Windows：直接執行新版的安裝程式，不必先解除安裝。已經開著的 App 要關掉重開，才會用到新版。
- Linux：下載新版，照同樣的步驟再裝一次，不必先移除。套件沒有套件庫，不會跟著系統更新。
- Android 版從 Google Play、iOS 版從 App Store 安裝與更新。

## 字在和其他輸入法有什麼關係？

內建的「字在自建字根表（依部件與筆順規則自建）」以大易輸入法的字根為基礎，拆字碼由程式依字在的取碼規則、全字庫的部件與筆順資料，以及人工指定與調整的字根清單產生，不是任何輸入法廠商的官方字根表。字在與任何輸入法廠商沒有合作或隸屬關係，也未經其背書。

詞庫裡收了大易、倚天、字在這類輸入法的名稱，只是讓你打得出這些詞。字在與任何輸入法廠商沒有合作或隸屬關係，也未經其背書。

有些字的拆法可能和你習慣的不同。電腦版可以在「字在設定」的「擴充字根表」分頁替這些字加上你習慣的輸入碼。

## 可以用自己的字根表嗎？

電腦版與 Android 版可以匯入 `.cin` 格式的字根表。請使用你有權使用的 `.cin` 檔，匯入的字根表只供你自己使用。除了由全字庫開放資料轉出的倉頡形碼表，字在不附、也不提供下載任何第三方的字根表檔案。

## 為什麼有些字打不出來？

內建字根表收錄 Unicode 擴充區的字，大多要另外安裝全字庫字型才看得到。看不到的字，預設不會出現在候選字視窗。電腦版安裝字型的方式見 [擴充區的字](guide-macos.md#擴充區的字)。

## Windows 跳出安全警告怎麼辦？

Windows 版與 Linux 版還沒有數位簽章，安裝前請先照安裝說明核對 SHA-256。Windows 會跳出安全警告；開了「智慧型應用程式控制」或由公司、學校管理的電腦，可能裝不起來，或裝好了也用不了字在。步驟與判斷方式見 [安裝與使用（Windows）](guide-windows.md#安裝)。

## 解除安裝後，我的資料會刪掉嗎？

- 電腦版：解除安裝不會刪除你的詞庫、擴充字根表、設定、匯入的資料更新檔、動態字序的紀錄，以及 Windows 版的記錄檔。位置與刪除方式見 [隱私權政策的「資料存在哪裡」](../PRIVACY.md#資料存在哪裡)。
- Android 版：選項、匯入的字根表副本、動態字序的紀錄與「我的詞庫（注音詞）」，會在清除 App 的儲存空間或解除安裝時刪除；你原本的字根表檔案不受影響。重新安裝字在時，Android 可能從系統備份還原動態字序的紀錄；想清掉的話，可以在字在 App 按「全部還原」。
- iOS 版：選項、動態字序的紀錄與「我的詞庫（注音詞）」會在刪除 App 時一起刪除。

## 怎麼回報問題或提出建議？

請到 [Issues](https://github.com/zizai-ime/zizai-ime/issues) 回報。Issues 是公開的，任何人都看得到：請不要貼上字根表內容、詞庫或打字內容，也不要直接貼記錄檔的原文。

隱私、個人資料與權利相關的問題，聯絡方式見 [隱私權政策的「聯絡與回報問題」](../PRIVACY.md#聯絡與回報問題)，不要貼在公開的 Issues。
