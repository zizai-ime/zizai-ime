# 常見問題

## 字在是什麼？

「字在」是以大易輸入法的字根為基礎，依字的部件與筆順重新拆碼的中文字根輸入法，為正體中文（繁體）設計。內建字根表，裝好就能打字。見 [首頁](../README.md)。

## 支援哪些系統？

| 系統 | 需求 |
|---|---|
| macOS | macOS 13 以上，支援 Apple 晶片與 Intel |
| Windows | Windows 10、11。64 位元與 32 位元的檔案不同 |
| Linux | x86_64。IBus 與 Fcitx5 都能用 |
| Android | Android 8 以上 |
| iPhone、iPad | iOS 17、iPadOS 17 以上 |

各版本的版本號與下載見 [首頁的下載](../README.md#下載)，安裝步驟見各平台的安裝與使用：[macOS](guide-macos.md)、[Windows](guide-windows.md)、[Linux](guide-linux.md)、[Android](guide-android.md)、[iPhone、iPad](guide-ios.md)。

## 要付費嗎？

不用。字在是免費軟體，個人或工作上使用都可以；但目前沒有開放原始碼，也不是開源軟體。見 [使用條款](../LICENSE.md)。

## 會不會收集我打的字？

不會。

- 字在沒有把你打的字、詞庫、擴充字根表或記錄檔傳給字在開發小組的功能，也不回傳使用統計，不放廣告。
- 電腦版的輸入法本體沒有連網的功能。只有在「字在設定」按「檢查更新」或「下載並看改了哪些字」時，才會連到 GitHub，請求裡沒有你的資料；不會自動檢查。
- Android 版沒有網路權限；iOS 版不要求「允許完整取用」，iOS 不讓字在的鍵盤連網。
- Windows 版預設會在你的電腦上寫一份記錄檔，記下啟用、載入、錯誤這類事件，以及當時在用的 App 名稱；不記錄你打的字。

詳細內容見 [隱私權政策](../PRIVACY.md)。

## 字根表怎麼更新？

電腦版在「字在設定」的首頁按「檢查更新」。有新的資料更新檔時，按「下載並看改了哪些字」，看過改了輸入碼的字再按「套用」，不必重裝字在。詞庫、擴充字根表與設定不受影響，想換回內建的資料，按「改回內建資料」。見 [版本與更新](guide-macos.md#版本與更新)。

也可以自己從 [zizai-data 的 Releases](https://github.com/zizai-ime/zizai-data/releases) 下載資料更新檔（ `.zizaipack` ），在首頁按「匯入資料更新檔…」。

## 怎麼升級到新版？

- macOS：「檢查更新」看到新版時，按「前往下載頁」，下載新的安裝檔，照安裝步驟裝一次。詞庫、擴充字根表與設定都會保留。
- Windows：直接執行新版的安裝程式，不必先解除安裝。已經開著的 App 要關掉重開，才會用到新版。
- Linux：下載新版，照同樣的步驟再裝一次，不必先移除。套件沒有套件庫，不會跟著系統更新。
- Android 版從 Google Play、iOS 版從 App Store 安裝與更新。

## 字在和其他輸入法有什麼關係？

內建的「字在自建字根表（依部件與筆順規則自建）」以大易輸入法的字根為基礎，拆字碼由程式依字在的取碼規則、全字庫的部件與筆順資料，以及人工指定與調整的字根清單產生。字在與任何輸入法廠商沒有合作或隸屬關係，也未經其背書。

有些字的拆法可能和你習慣的不同。電腦版可以在「字在設定」的「擴充字根表」分頁替這些字加上你習慣的輸入碼。

## 可以用自己的字根表嗎？

電腦版與 Android 版可以匯入 `.cin` 格式的字根表。請使用你有權使用的 `.cin` 檔，匯入的字根表只供你自己使用。字在不附、也不提供下載任何第三方的字根表檔案。

## 為什麼有些字打不出來？

內建字根表收錄 Unicode 擴充區的字，大多要另外安裝全字庫字型才看得到。看不到的字，預設不會出現在候選字視窗。電腦版安裝字型的方式見 [擴充區的字](guide-macos.md#擴充區的字)。

## Windows 跳出安全警告怎麼辦？

Windows 版與 Linux 版還沒有數位簽章，安裝前請先照安裝說明核對 SHA-256。Windows 會跳出安全警告；開了「智慧型應用程式控制」或由公司、學校管理的電腦，可能裝不起來，或裝好了也用不了字在。步驟與判斷方式見 [安裝與使用（Windows）](guide-windows.md#安裝)。

## 解除安裝後，我的資料會刪掉嗎？

- 電腦版：解除安裝不會刪除你的詞庫、擴充字根表、設定、匯入的資料更新檔，以及 Windows 版的記錄檔。位置與刪除方式見 [隱私權政策的「資料存在哪裡」](../PRIVACY.md#資料存在哪裡)。
- Android 版：選項與匯入的字根表副本，會在清除 App 的儲存空間或解除安裝時刪除；你原本的字根表檔案不受影響。
- iOS 版：選項會在刪除 App 時一起刪除。

## 怎麼回報問題或提出建議？

請到 [Issues](https://github.com/zizai-ime/zizai-ime/issues) 回報。Issues 是公開的，任何人都看得到：請不要貼上字根表內容、詞庫或打字內容，也不要直接貼記錄檔的原文。

隱私、個人資料與權利相關的問題，聯絡方式見 [隱私權政策的「聯絡與回報問題」](../PRIVACY.md#聯絡與回報問題)，不要貼在公開的 Issues。
