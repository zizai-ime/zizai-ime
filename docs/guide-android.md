# 安裝與使用（Android）

這一頁是 Android 版。「字在」是以大易輸入法的字根為基礎，依字的部件與筆順重新拆碼的中文字根輸入法，為正體中文（繁體）設計。內建字根表，裝好就能打字；在手機上處理輸入，不自行連網。

## 系統需求

Android 8 以上。目前的版本是 1.0.0。

## 安裝

從 Google Play 安裝：

<p align="center">
  <a href="https://play.google.com/store/apps/details?id=studio.mosil.ime.zizai"><img src="images/badge-google-play.png" width="188" height="56" alt="在 Google Play 下載字在（Android）"></a>
</p>

裝好後打開字在，照畫面上的步驟設定。

Android 在啟用輸入法時，可能會提醒輸入法可以存取你輸入的文字；提醒的文字依系統版本與裝置而不同。

## 打字與選字

- 40 個輸入鍵依實體鍵盤的位置排列，鍵面顯示字根與實體鍵的字母；按過的字根顯示在候選列左邊。
- 打碼的時候，候選列就會預覽候選，點一下就送出；空白鍵送出第 1 個候選。
- 三碼（由四碼推導）和四碼不用切換。
- 長按按鍵可以選注音、全形字母或符號，內容和電腦版對應的符號按鍵組合相同，見 [符號字根表](symbols.md)。
- 從中文切到數字符號頁時，標點是全形。
- 使用 TalkBack 時，可以從動作選單選符號。

## 外接鍵盤

接上藍牙或 USB 鍵盤時，打法和電腦版相同，螢幕上只留一列候選；按 Caps Lock 切換中英。電腦版的打法見 [安裝與使用](guide-macos.md#打字與選字)。

## 擴充字根表

可以匯入 `.cin` 格式的擴充字根表。請確認你有權匯入及使用該檔案；字在不附、也不提供下載任何第三方的字根表檔案。

## 字根表

內建「字在自建字根表（依部件與筆順規則自建）」：拆字碼由程式依字在的取碼規則、全字庫的部件與筆順資料，以及人工指定與調整的字根清單產生，有些字的拆法可能和你習慣的不同。字在與任何輸入法廠商沒有合作或隸屬關係，也未經其背書。

## 隱私

你打的字只在手機上處理。字在沒有網路權限，不收集按鍵或輸入內容，不放廣告，沒有追蹤功能。設定與匯入的字根表不參與 Android 的雲端備份與裝置間移轉。見 [隱私權政策](../PRIVACY.md#android-版)。

## 目前的限制

- 系統字型顯示不出來的字，預設不會出現在候選。

遇到問題請到 GitHub 的 [Issues](https://github.com/zizai-ime/zizai-ime/issues) 回報。Issues 是公開的：請不要貼上字根表內容、詞庫或打字內容。
