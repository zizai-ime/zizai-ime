# 安裝與使用（iPhone、iPad）

這一頁是 iPhone、iPad 版。「字在」是以大易輸入法的字根為基礎，依字的部件與筆順重新拆碼的中文字根輸入法，為正體中文（繁體）設計。內建字根表，裝好就能打字；不需要「允許完整取用」，不連網。

## 系統需求

iOS 17、iPadOS 17 以上。目前的版本是 1.0.0。

## 新增鍵盤

打開「設定」→「一般」→「鍵盤」→「鍵盤」→「新增鍵盤⋯」，選「字在」。也可以打開字在，照畫面上的步驟設定。

## 打字與選字

- 40 個輸入鍵依實體鍵盤的位置排列，鍵面顯示字根與實體鍵的字母；按過的字根顯示在候選列左邊。
- 打碼的時候，候選列就會預覽候選，點一下就送出；空白鍵送出第 1 個候選。
- 三碼（由四碼推導）和四碼不用切換。
- 長按按鍵可以選注音、全形字母或符號，內容和電腦版對應的符號按鍵組合相同，見 [符號字根表](symbols.md)。
- 從中文切到數字符號頁時，標點是全形。
- iPad 的版面依實體鍵盤排列，有 Tab 鍵與收起鍵盤的鍵。
- 使用 VoiceOver 時，可以用轉子的「動作」選符號。

## 字根表

內建「字在自建字根表（依部件與筆順規則自建）」：拆字碼由程式依字在的取碼規則、全字庫的部件與筆順資料，以及人工指定與調整的字根清單產生，有些字的拆法可能和你習慣的不同。字在與任何輸入法廠商沒有合作或隸屬關係，也未經其背書。

## 隱私

你打的字只在 iPhone、iPad 上處理。字在不需要「允許完整取用」，iOS 不讓鍵盤連網；字在不收集按鍵或輸入內容，不放廣告，沒有追蹤功能。選項不進 iCloud 與電腦的備份。見 [隱私權政策](../PRIVACY.md#ios-版)。

## 目前的限制

- 系統字型顯示不出來的字，不會出現在候選。
- 密碼與電話號碼欄位，iOS 一律使用系統鍵盤。
- iPad 接上實體鍵盤時，iOS 不會把按鍵交給第三方鍵盤。

遇到問題請到 GitHub 的 [Issues](https://github.com/zizai-ime/zizai-ime/issues) 回報。Issues 是公開的：請不要貼上字根表內容、詞庫或打字內容。
