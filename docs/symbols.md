# 字在符號字根表

這份表列出字在用 `=` 打標點與符號的按法，以預設的「按鍵組合」為準（字在 1.1.0）。內容由程式依輸入法的內建清單產生，和實際打出來的一致。

## 怎麼打

- 沒有組字時先按 `=` ，組字區出現「符」，再按一顆鍵。
- 那顆鍵只有一個符號時直接送出；有多個時打開候選字視窗，用空白鍵或選字鍵選。
- 選字鍵依序是 空白、`'`、`[`、`]`、`-`、`\`、`6`、`7`、`8`、`9`、`0`，表裡「按法」的最後一鍵就是選字鍵。
- 看的是哪一顆鍵，按不按 Shift 都一樣，例如 `=` `/` 和 `=` `?` 一樣。
- 候選字視窗開著時再按一次同一顆鍵，換成第二層清單，例如 `=` `0` `0` 、`=` `.` `.` 。第二層的第 1 個是那顆鍵的注音符號（標準注音鍵盤），只有一個的直接送出，例如 `=` `;` `;` 打出 ㄤ；數字鍵接著是羅馬數字的大寫、小寫，例如 `=` `1` `1` 是 ㄅ Ⅰ ⅰ。
- 字母鍵沒有第一層：按 `=` 加字母會等下一個鍵，再按一次同一個字母列出注音、全形大寫、全形小寫，例如 `=` `q` `q` 是 ㄆ Ｑ ｑ。下一個鍵不是同一個字母時取消 `=` ，照平常打字。
- 按兩下 `=` 列出數學符號，再按一次 `=` 換成第二層。按 Backspace 回到上一層。
- 候選字視窗開著時直接打下一個字，會先送出第 1 個。
- 中文標點和第二層固定，不能改；夾在中文標點之間的符號（ `=` `.` 的 … ﹀ ）也不能停用。其他內建的符號可以在設定 App 的「符號」分頁停用；也可以替任何一顆鍵加自己的符號，接在內建的後面。替字母鍵加了符號時，`=` 加字母會先列出你加的符號，再按一次同一個字母才是第二層。

## 清單選字模式

輸入法選單的「符鍵（=）用清單選字」打開時，按 `=` 會直接列出「符」清單，`'` 列出「標」清單，`=` `=` 再按一顆鍵列出那顆鍵的全形符號。這份表以預設的按鍵組合為準。
