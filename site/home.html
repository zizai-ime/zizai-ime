特色 1／4

裝好就能打字

內建字根表

「字在自建字根表（依部件與筆順規則自建）」，收錄 7 萬多字，含 Unicode 擴充區的字。有些字的拆法可能和你習慣的不同，可以在「字在設定」的「擴充字根表」分頁替這些字加上你習慣的輸入碼。

擴充區的字大多要另外安裝全字庫字型才看得到，見安裝方式。

三碼與四碼並存

三碼（由四碼推導）和四碼都能直接打，不用切換。

推導二碼

大易的三碼、四碼字，也能用第一碼加最後一碼打出，排在原有的二碼字之後；不需要時可以在「字在設定」關閉。

macOS、Windows；Linux 1.3.1 起。

標點與符號

按 = 再按一顆鍵，見符號字根表。

特色 2／4

四種輸入法

macOS 版與 Windows 版都有四種輸入法：

  • 大易
  • 倉頡
  • 標準注音
  • 倚天 26 鍵（標準注音的另一種鍵盤排列）

macOS

在輸入法選單切換，見安裝與使用。

Windows

在工作列的「中」「英」按鈕按右鍵切換。

Linux

這版（1.3.0）是大易。

特色 3／4

越打越順手

動態字序

依你自己選過的字調整候選順序，選了才會換位；很久沒選的字會慢慢退回去。所有打法共用一份次數。

macOS、Windows。

資料更新

字根表有更新時，在「字在設定」的首頁按「檢查更新」，下載資料更新檔，看過改了哪些字再套用，不必重裝字在。

擴充與自訂

支援 .cin 格式，可以補字、自訂輸入碼、停用不要的字。

請使用你有權使用的 .cin 檔，匯入的字根表只供你自己使用。「字在」不附、也不提供下載任何第三方的字根表檔案。

特色 4／4

打字不連網

輸入法本體不連網

輸入法本體沒有連網的功能，不記錄打字內容。

只記在這台裝置

動態字序只在這台裝置上記下你選過的每個字各選了幾次與調整過的候選位置，不記句子、前後文、時間。

按了才連 GitHub

只有在「字在設定」按「檢查更新」或下載資料更新檔時，才會連到 GitHub，不會自動連網，也不會送出你的任何資料。

不放廣告、沒有追蹤
