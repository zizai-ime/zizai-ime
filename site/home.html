特色 1／5

裝好就能打字

內建字根表

「字在自建字根表（依部件與筆順規則自建）」，收錄 7 萬多字，含 Unicode 擴充區的字。有些字的拆法可能和你習慣的不同，可以在「字在設定」的「擴充字根表」分頁替這些字加上你習慣的輸入碼。

擴充區的字大多要另外安裝全字庫字型才看得到，見安裝方式。

三碼與四碼並存

三碼（由四碼推導）和四碼都能直接打，不用切換。

推導二碼

大易的三碼、四碼字，也能用第一碼加最後一碼打出，排在原有的二碼字之後；不需要時可以在「字在設定」關閉。

macOS、Windows、Linux。

標點與符號

按 = 再按一顆鍵，見符號字根表。

四

特色 2／5

四種輸入法

五個平台都有四種輸入法：

  • 大易
  • 倉頡
  • 標準注音
  • 倚天 26 鍵（標準注音的另一種鍵盤排列）

macOS

在輸入法選單切換，見安裝與使用。

Windows

在工作列的「中」「英」按鈕按右鍵切換。

Linux

在輸入法選單切換。

手機版長按鍵盤上的「英／中」鍵切換。

詞

特色 3／5

打詞與聯想

注音打詞 1.4.0 起五個平台都有；首碼聯想與字彙建議 macOS、Windows、Linux 版有，手機版沒有。

注音打詞

標準注音預設打詞：打第一個鍵就有候選，可以連打幾個字再選詞，每個字只打聲母也找得到；選過的詞會往前排。也可以切回逐字。

1.4.0 起五個平台都有；倚天 26 鍵這一種排列，這一版還是逐字。

首碼聯想

送出一個字後，打下一個字的第一個鍵，游標旁就提示接在後面的詞。按 Tab，只有一個詞就直接送出，兩個以上時輪流選，按空白鍵送出，或直接打下一個字。提示出現的時機可以選。

1.4.0 起，macOS、Windows、Linux 版的大易與標準注音（打詞或逐字都有），預設開啟；詞庫可以勾選樂詞網各領域的名詞。字在與任何輸入法廠商沒有合作或隸屬關係，也未經其背書。

字彙建議

剛送出字、還沒打下一個字時，先用淡色顯示可能接著打的詞；按 Tab 採用，有幾個建議時輪流選，按空白鍵送出，或直接打下一個字。終端機類 App 與密碼欄位不顯示。

1.4.0 起，macOS、Windows、Linux 版的大易與標準注音，預設關閉，見安裝與使用。字在與任何輸入法廠商沒有合作或隸屬關係，也未經其背書。

順

特色 4／5

越打越順手

動態字序

依你自己選過的字調整候選順序，選了才會換位；很久沒選的字會慢慢退回去。所有打法共用一份次數。

五個平台都有；1.4.0 起標準注音打詞時，選過的詞也會往前排。

資料更新

字根表有更新時，在「字在設定」的首頁按「檢查更新」，下載資料更新檔，看過改了哪些字再套用，不必重裝字在。

擴充與自訂

支援 .cin 格式，可以補字、自訂輸入碼、停用不要的字。

請使用你有權使用的 .cin 檔，匯入的字根表只供你自己使用。除了由全字庫開放資料轉出的倉頡形碼表，「字在」不附、也不提供下載任何第三方的字根表檔案。

特色 5／5

打字不連網

輸入法本體不連網

輸入法本體沒有連網的功能，也不保存打字紀錄。

記在你的裝置上

動態字序在這台裝置上記下你選過的每個字詞各選了幾次與調整過的候選位置，不記句子、前後文、時間。首碼聯想與字彙建議只在打字當下看你剛送出的幾個字，不存下來。手機版另把詞庫沒有的詞記進「我的詞庫（注音詞）」，可以關掉。

按了才連 GitHub

只有在「字在設定」按「檢查更新」或下載資料更新檔時，才會連到 GitHub，不會自動連網，也不會送出你的任何資料。

不放廣告、沒有追蹤
